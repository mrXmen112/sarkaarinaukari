## IndexNow

- Dynamic job/stage publishes already call `src/lib/indexNow.ts` from `src/app/actions/admin.ts` and `src/app/actions/quickPublish.ts`.
- Static landing pages have no publish event. After deploy run:

```bash
npm run submit:indexnow -- /bihar/12th-pass-jobs
```

- With no arguments the script submits `/`, `/bihar`, `/bihar/12th-pass-jobs`, `/jobs/12th-pass` and `/exams/bpsc-70th`.
- The key must be live at `https://www.sarkaarinaukri.online/<INDEXNOW_KEY>.txt`.
